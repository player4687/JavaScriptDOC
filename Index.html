Introduction

JavaScript is a lightweight, interpreted, object oriented programming language with first class functions, most commonly used as part of web pages whose implementations allow client sided scripts to interact with the user.

It is a multi-paradigm language, supporting event driven, functional, and imperative (including object oriented and prototype-based) programming styles.

JavaScript runs in every browser without needing a compiler, and is one of the three core technologies of the World Wide Web, alongside HTML and CSS.

What you should already know

This guide assumes you have the following basic background:

  • A general understanding of the Internet and the World Wide Web (WWW).
  • Working knowledge of HyperText Markup Language (HTML).
  • Some programming experience, though if you don't have this, it's not a big problem.

Even complete beginners should be able to follow along without too much difficulty.

JavaScript and Java

JavaScript and Java are similar in some ways but fundamentally different in others. The JavaScript language resembles Java but does not have Java's static typing and strong type checking.

JavaScript follows most Java expression syntax, naming conventions, and basic control-flow constructs, which was the reason it was renamed from LiveScript to JavaScript.

Unlike Java's compiletime system of classes built by declarations, JavaScript supports a runtime system based on a number of primitive data types, including Number, Boolean, and String.

Hello World

To get started with writing JavaScript, open your browser's developer console and type the following:

console.log("Hello, World!");

This is a very simple example, but it introduces the primary tool you'll use for the rest of this documentation: console.log(). This method prints, or "logs," a message to the console.

This message is meant to help you understand what's going on in your code. You can log numbers, strings, booleans, objects, arrays basically any valid JavaScript object.

Variables

Variables are the basic units of storage in a program. Variables are declared with the var, let, or const keyword.

let box_name = value;

This statement declares a variable with the given name, and can also initialize the variable, that is, set its value, with a given value.

  • var declares a function scoped or globally scoped variable.
  • let declares a block-scoped, local variable.
  • const declares a block-scoped, read-only named constant.
Comments

The number of comments in a given script has no effect on how it executes. Comments are added purely to help others (and yourself, later) understand the code, and are ignored by the JavaScript engine.

JavaScript comments can be used to explain JavaScript code, and to make it more readable, as well as to prevent execution when testing alternative code.

// This is a single-line comment /* This is a multi-line comment */
Data types

The latest ECMAScript standard defines eight data types, seven of which are considered "primitive" and one which is a compound type.

  • Number for any kind of number.
  • String for strings, textual data.
  • Boolean for true and false.
  • Object for more complex data structures.

All types except objects define immutable values represented directly at the lowest level of the language.
